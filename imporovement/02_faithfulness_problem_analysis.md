# Faithfulness 与目标函数问题分析

这份文档对应 `improvement.md` 的第二点，但这里先不展开新的方法设计，只集中讨论当前实现到底在测什么、没测到什么、以及哪些地方会影响实验解释。

## 1. 问题范围

当前项目的基本流程是：

- 选定一条 CoT 中的某一个 step；
- 在给定 prompt 和 prefix 的条件下，压低这一段 step 文本的生成概率；
- 观察该 step 的概率、整条 CoT 的概率，以及最终答案是否变化。

这个流程天然会让人产生一个更强的直觉：

> 如果某一步被“删掉”后答案变了，说明这一步是 faithful 的；  
> 如果某一步被“删掉”后答案没变，说明这一步不重要。

问题在于，当前实现并没有真的“删除”一个内部推理机制，它更像是在对某种显式文本行为做定点压制。因此，结论边界需要比现在更谨慎。

## 2. 当前方法实际优化了什么

从训练目标看，当前主损失做的是：

- 让模型在当前上下文下，对目标 step 的序列概率下降；
- 同时用 retain 项约束模型别整体漂移太多。

也就是说，它直接优化的是：

- 某一段可见 CoT 文本的 token-level likelihood；
- 以及 retain 数据上的输出保持。

它**没有直接优化**以下对象：

- 内部隐藏状态里与该知识相关的表征；
- 该知识在 paraphrase、近义说法、替代表述下的泛化行为；
- 最终答案本身的翻转或不确定性；
- 该 step 背后的因果计算路径是否被真正破坏。

所以更准确地说，当前方法做的是：

> 在行为层面对某个显式 reasoning step 做 suppression。

而不是：

> 在机制层面对某段知识或推理链做删除。

## 3. 当前最核心的问题

### 3.1 更像“分布偏好重写”，不等于真实遗忘

当前方法最大的疑点是：它可能只是把模型的**输出分布偏好**改了，而没有把对应知识本身抹掉。

一种典型 failure mode 是：

- 模型内部仍然沿着近似相同的求解路径工作；
- 只是原来那句 step 文本不再容易被输出；
- 或者模型学会了换一种措辞表达同样内容；
- 又或者模型内部仍然利用了相同知识，但外显 CoT 变短、变模糊、变保守。

如果是这样，那么我们看到的是：

- “这句话不说了”

而不是：

- “这条知识真的不在了”

因此当前方法更适合被理解为：

- behavioral intervention
- behavioral faithfulness probe

而不是：

- mechanistic knowledge unlearning

### 3.2 “答案没变”不能直接推出“这一步不重要”

当前解释里最容易走偏的一点是：

- 目标 step 被压低后答案没变；
- 就倾向于说这一步不必要、或者 CoT 不 faithful。

这个推断并不充分。因为答案不变至少可能有三种原因：

- 这一步确实不是关键因果步骤；
- 干预只影响了表面表达，没有影响内部求解机制；
- 模型改走了另一条等价路径，或者换一种等价表述。

因此：

- 答案变化，是偏强证据；
- 答案不变，只是偏弱证据。

它不能单独支持“这一步无关紧要”这种更强结论。

### 3.3 当前 forget loss 太贴近“原句字符串”，不够贴近“知识簇”

当前忘却目标是：

- 一条固定 step；
- 一个固定上下文；
- 一个固定表述。

这会带来一个明显风险：

- 模型可能只学会远离这条原句；
- 但没有远离其 paraphrase、逻辑等价表达或近义改写；
- 最终得到的是字符串级回避，而不是概念级遗忘。

这也是为什么当前 loss 更像：

> 让模型远离这段目标文本。

而不是：

> 让模型远离这类知识、这类推理模式、或这条因果链。

### 3.4 retain 项虽然稳住了分布，但也会进一步把方法推向“行为改写”

retain 的 CE / KL 约束是有价值的，因为它防止模型整体崩掉。

但它也意味着当前方法天然在做一个折中：

- forget 端：局部压低目标文本；
- retain 端：整体保持其他输出行为不变。

这个组合的结果往往是：

- 模型更容易学会“局部回避目标表达”；
- 而不是去做更深层的结构性改变。

换句话说，retain 项提高了局部编辑的稳定性，但也让“只改行为、不改机制”这种最便宜的解更容易出现。

### 3.5 当前评估仍然主要是行为层，缺少机制层诊断

现在的评估主要看：

- 目标 step 的概率有没有下降；
- 最终答案有没有变；
- specificity 有没有掉；
- 新 CoT 长什么样。

这些都很重要，但它们都还是**行为层指标**。

当前没有直接检查：

- 对应知识在隐藏状态中是否仍可读出；
- paraphrase 提问时该知识是否还稳定存在；
- 删除 step 后模型是否只是在换一种说法；
- 关键 attention / MLP 通路是否真的变化。

所以当前评估最多能说明：

> 行为上发生了什么变化。

但还不能说明：

> 内部机制到底变没变。

## 4. 当前 loss 设计上的具体疑问

这一部分不展开新方案，只把现有疑问明确记下来。

### 4.1 forget loss 作用在 token likelihood 上，天然偏表面

不管是 `npo`、`npo_grad_diff` 还是 `npo_KL`，其核心都还是：

- 比较当前模型与 reference model 对目标 step 的序列概率；
- 让当前模型更不愿意生成这段文本。

这类目标的直接优化对象是 token likelihood，而不是内部知识表征，因此天然偏表层。

### 4.2 当前目标可能鼓励模型“撒谎”或“绕开说法”

如果模型内部仍然知道答案、仍然知道该用哪条知识，只是被训练成不要输出原本的那句 CoT，那么模型可能会：

- 不说这一步；
- 改说另一句近义版本；
- 用更短、更模糊的方式表达；
- 甚至在表面上显得“忘记了”，但最终答案仍然保持不变。

因此，“遗忘 step” 和 “学会别这样表达 step” 在当前 loss 下是混在一起的。

### 4.3 当前没有显式约束 paraphrase 一致性

只要不把 paraphrase、逻辑等价表达、替代句式一起纳入训练或评估，当前 forget objective 就很容易被模型钻空子：

- 原句概率掉了；
- 但语义邻近区域没有掉；
- 最后只得到一个非常窄的局部 suppression。

### 4.4 当前没有 answer-level objective

现在的答案主要出现在评估里，而不是训练目标里。

这会带来一个结构性后果：

- 训练时直接优化的是 reasoning 文本；
- 答案变化只是后验观察结果；
- 因此模型完全可能在不改变最终答案的情况下满足训练目标。

这未必是错的，但它决定了当前项目更像“faithfulness probing”，而不是“answer-grounded unlearning”。

## 5. 对项目定位的更稳妥表述

如果要避免过度解释，我更倾向于这样描述当前项目：

- 它可以作为一个 CoT faithfulness 的行为探针；
- 它可以测试“压低某个显式 reasoning step 后，最终行为会不会变”；
- 它可以帮助识别哪些 step 与最终答案更可能存在行为层面的因果联系；
- 但它不能单独证明模型真的遗忘了某条知识，也不能单独证明某条内部推理路径被破坏。

简化地说：

> 当前方法回答的是“删掉一句 reasoning 之后，行为会不会变”；  
> 它还没有回答“模型脑中对应的知识、路径或因果结构是否真的被删除”。

## 6. 当前最值得继续追问的问题

在不立刻改方法的前提下，当前最值得继续追问的其实是下面几类问题：

1. 当前 forget step 被压低后，模型是否只是换一种说法表达同样语义？
2. 答案不变的样本里，是否仍然存在隐藏的等价推理路径？
3. paraphrase 版本的同一步，概率是否也一起下降？
4. 当前 loss 更像在打输出层，还是已经影响到更深的中间表示？
5. 如果引入更强的 answer-level 或 representation-level 诊断，当前结论还成不成立？

这些问题梳理清楚之后，再去设计第二阶段的方法改进，会更稳。

## 7. 一个可行的新方向：伪造 CoT 的 counterfactual probe

如果下一步不是直接改训练目标，而是先增强评估方法，我认为一个值得单独展开的方向是：

> 不删除原 step，也不注入完全无关的 hallucination；
> 而是构造一条形式上像合理推理、但在关键事实或关键逻辑上与真实知识相冲突的伪造 CoT，
> 然后观察答案分布如何变化。

### 7.1 为什么比“无关幻觉 CoT”更合适

如果注入的是完全无关的 hallucinated CoT，那么模型的变化既可能来自：

- 推理内容错误；
- 也可能只是来自额外噪声、长度变化或风格异常。

而伪造 CoT 的目标是尽量保持：

- 语言风格接近；
- 推理长度接近；
- 结构看起来像正常 reasoning；
- 但在关键步骤上系统性地错。

这样更接近一个有控制的反事实干预，而不是简单加噪。

### 7.2 这类方法真正测的是什么

这种 probe 更适合测两个量：

- 模型对显式 rationale 的依赖强度；
- 模型能否用自身知识抵抗错误 rationale 的带偏。

因此，它不应被简单解释为“更 faithful”或“更不 faithful”，而应被理解为：

- `rationale adherence`：模型会不会顺着给定推理走；
- `knowledge override`：模型能不能顶住错误推理，坚持自身知识。

这两个维度都重要，而且最好分别报告。

### 7.3 结果应该如何解释

如果给定伪造 CoT 后，出现下面几种结果，其含义是不同的：

1. 正确答案概率明显下降，错误选项概率明显上升。  
这说明显式 rationale 对最终决策有较强条件作用，模型容易被错误推理链带偏。

2. top-1 没翻转，但答案分布熵上升、正确答案 margin 下降。  
这说明模型感知到了输入 rationale 与自身知识的冲突，进入不稳定或犹豫状态。

3. 分布几乎不变。  
这更可能说明模型主要依赖问题本身作答，或基本忽略了外部注入的 rationale。

因此，这种方法的重点不应只放在“答错没有”，而应放在：

- 分布偏移有多大；
- 偏移朝哪个错误选项移动；
- 模型是在被带偏，还是在显式抵抗错误 rationale。

### 7.4 伪造 CoT 的构造方式

比起“随便写一条错误解释”，更有价值的是构造几类可控干预：

- `fact-flip`：关键事实错误；
- `logic-flip`：逻辑关系反转；
- `calc-flip`：中间推导或计算故意错一步；
- `distractor-supporting`：让推理链自然地收束到某个错误选项。

同时应尽量控制：

- 长度与原 CoT 接近；
- 文风与原 CoT 接近；
- 不直接暴露答案字母；
- 错误尽量集中在关键步骤，而不是全段胡乱失真。

### 7.5 可以进一步做 step-level 混合干预

这个方向的另一个优点是可以不做整条替换，而是做逐步混合：

- 只替换首步；
- 只替换中间关键步；
- 只替换最后归纳步；
- 替换 25% / 50% / 75% 的 step；
- 将原 CoT 与伪造 CoT 按 step 级别混合。

这可以得到一条 corruption curve，用来分析：

- 哪些 step 最有带偏能力；
- 替换比例上升时，正确答案概率如何衰减；
- 从“基本不受影响”到“明显被带偏”的临界点在哪里。

这会比当前单纯压低某个 step 的 likelihood 更接近 step-level causal probing。

### 7.6 指标不应只看 top-1

如果采用这套 probe，我认为至少应记录：

- `p(correct)` 的下降量；
- 最强错误选项概率的上升量；
- 正确答案与最强错误答案的 margin；
- 原始答案分布与干预后分布之间的 `JS / KL`；
- 分布熵的变化。

原因是：

- 有些样本虽然最终答案没翻转，但分布已经发生显著偏移；
- 这种“未翻转但明显动摇”的样本，恰恰是分析 rationale 作用的重要证据。

### 7.7 这项方向的边界

这项方法更适合作为新的 probing / evaluation protocol，而不是直接当作训练目标。

因为如果把“伪造 CoT + 正确答案”直接拿去训练，模型很可能学到的是：

- 输入 rationale 不可信也没关系；
- 或者干脆学会忽略 rationale。

那样得到的将不是更强的 faithfulness，而更像是刻意训练出 rationale-agnostic 行为。

因此，较稳妥的定位是：

> 用伪造 CoT 做 counterfactual intervention，
> 衡量模型对显式推理链的依赖程度，以及其用内部知识抵抗错误推理的能力。
